🤝 How “Get it” works
  1. Tap “Get it →” — it opens the app’s page on GitHub, where its maker keeps the goods.
  2. Copy the link from your browser’s address bar and paste it to Gideon — say “what does this do” or “install this”.
  3. Gideon inspects it first — these are brand-new apps from strangers, and code is checked before anything gets installed on your gear. Then Gideon installs it or tells you exactly what it needs (Node, Docker, whatever).

⚡ Or tap Add to Gideon on any card — it copies the install request to your clipboard; paste it in the dashboard and Gideon vets & installs it immediately.

DIY route: on the GitHub page tap the green Code button → Download ZIP, then follow the README. A Releases box on the right side = ready-made download, no coding needed.
